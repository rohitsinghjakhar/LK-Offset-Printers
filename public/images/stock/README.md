# Printing photography

Forty-eight real photographs downloaded from Pexels and optimized locally as WebP (the thirty-two product, industry, machine and step photos added later list their Pexels photo page as the source). All photos are used under the [Pexels License](https://www.pexels.com/license/), checked on 31 October 2026. Per-file credits, source URLs, dimensions and byte sizes are in [sources.json](./sources.json).

Pexels permits free website/commercial use and modification, with optional attribution. Do not imply that pictured people or businesses endorse L.K. Offset Printers, and do not redistribute these as a stock library or sell unaltered prints.

These are **illustrative stock photographs**, not photographs of L.K. Offset Printers' premises, employees or completed client work. Label them as illustrative wherever a visitor might otherwise infer they are actual company work. The workshop operator must not be presented as Mahendra Choudhary.

The complete set totals about 1.8 MB on disk; `next/image` serves each one resized to the width the page needs. Use responsive `next/image` sizes, a reserved aspect ratio, lazy loading below the fold, and preload only the actual above-the-fold hero image.
